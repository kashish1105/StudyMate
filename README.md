# StudyMate - Student Assignment & Study Manager

A native Android application built in **Java** and **XML** using **SQLite** to help students manage assignments, subjects, daily study schedules, and academic progress.

## Key Features
- **Splash Screen & Live Dashboard:** Displays real-time counts of Total, Pending, and Completed assignments.
- **Assignment Manager (CRUD):** Add, edit, delete, and mark assignments complete with `DatePickerDialog`, dynamic Subject dropdowns, and color-coded Priority Badges (High/Medium/Low).
- **Subject Manager:** Manage subjects and faculty details with one-tap subject-wise assignment filtering.
- **Daily Study Planner:** Organize daily study sessions by subject, topic, and time slot.
- **Calendar & Reminders:** Interactive `CalendarView` to check assignments due on specific dates.
- **Progress Report:** Visual progress bar and completion percentage analytics.

## Tech Stack
- **Language:** Java
- **UI:** XML, Material Design, CardView, RecyclerView
- **Database:** SQLite (`SQLiteOpenHelper`)
- **IDE:** Android Studio
